# 📚 Интерактивный навигатор по Википедии (на Selenium)

Консольное приложение на Python, которое позволяет интерактивно искать и просматривать статьи Википедии, используя браузер через Selenium. Пользователь может листать параграфы статьи или переходить на связанные страницы, как в "википедийном лабиринте".

## 🔍 Возможности

- Поиск любой статьи на Википедии
- Просмотр параграфов текущей статьи (в консоли)
- Переход по внутренним ссылкам и изучение других статей
- Возможность выхода на любом этапе

## 🧠 Как работает

1. Пользователь вводит поисковый запрос.
2. Скрипт открывает первую найденную статью на Википедии.
3. На каждом шаге предлагается выбрать:
   - 📄 Просмотр параграфов
   - 🔗 Переход на внутреннюю ссылку
   - 🚪 Выход

## 🛠️ Зависимости

- Python 3.7+
- [selenium](https://pypi.org/project/selenium/)
- WebDriver для вашего браузера (по умолчанию — Chrome)
